# **App Name**: Mundialify AI

## Core Features:

- Collectible Identity Form: A custom user interface for entering player statistics with automatic name capitalization and metric conversions for height and weight.
- Smart Drag & Drop Studio: An interactive file upload interface using HTML5 Canvas for real-time portrait previews and pre-processing.
- AI Portrait Kit Transformation: A multimodal AI tool that uses visual reasoning to intelligently overlay official Argentine national team kits onto user photos while preserving facial identity.
- Optimized Media Processor: Client-side image utility that leverages Canvas to resize portraits to a maximum of 1024px with JPEG quality optimization.
- HD Cromo Renderer: A custom rendering engine that generates a 3:4 digital sticker featuring FIFA branding, the Argentina flag, and stylized player data plaques.
- Digital Stamp Watermark: A secondary processing tool that overlays a high-definition semi-transparent brand watermark on generated images for security.
- Pro Share Hub: Integration with the Web Share API and automatic PNG export functionality using normalized file naming conventions.

## Style Guidelines:

- Primary Brand Red (#E30613): Evokes passion, dynamism, and the classic look of premium collectible sticker albums.
- Panini Yellow (#FFD700): High-visibility accent color used for secondary actions and energetic interface highlights.
- Base Palette: Midnight Pitch (#0A111F) for the application background, accented with Albiceleste (#75AADB) to honor the Argentina national theme.
- Headline font: 'Space Grotesk' for a technical, modern sports feel. Body font: 'Inter' for neutral, clear readability.
- Geometric icons with thin strokes and high contrast (black/white) to maintain structural clarity and legibility.
- Vertical, card-centric layout optimized for mobile-first sticker creation using modern CSS Grid and Flexbox.
- Subtle foil-shimmer transitions and smooth scroll-to-top effects to simulate the experience of opening physical trading cards.
